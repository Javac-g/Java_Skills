# Answers

This directory contains the written answers for Module 01.

Use:

`ANSWERS.md`

for your explanations of the engineering questions from the module README.

Rules:

- answer in your own words;
- explain reasoning, not only the final statement;
- include small code examples when useful;
- do not copy text directly from `THEORY.md`;
- it is acceptable to write "I am not sure" if you genuinely do not know — this helps identify weak topics;
- answers are reviewed and graded together with the implementation.
